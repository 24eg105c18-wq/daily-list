# Daylist — Simple To-Do List Application

A clean, minimal task dashboard inspired by the general workflow of modern task managers. Features include light/dark themes, Today / Upcoming / All Tasks / Completed views, projects, task descriptions, due dates, priorities, completion tracking, search, filters, and a daily progress summary.

- `frontend/` — HTML, CSS and JavaScript dashboard; runs locally in a browser and can be deployed to GitHub Pages.
- `backend/` — Java 17 + Spring Boot REST API with CRUD endpoints and an H2 database.

The interface uses its own name and styling and is not affiliated with Todoist. See each folder's README for setup instructions.
